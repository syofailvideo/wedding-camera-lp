## 登録の受け皿
LP内のフォームは Googleフォームの `formResponse` に直接POSTしている（非表示iframe経由）。
ページ遷移なしで送信が完了する。**2026-09-11に匿名POSTで実送信し、回答が着弾することを確認済み。**
送信に失敗した人向けに、フォーム単体へのリンクも文末に置いてある。

### 設問（5問）
| # | 設問 | entry ID | 必須 |
|---|---|---|---|
| 1 | メールアドレス | entry.2059212512 | ✅ |
| 2 | お名前 | entry.972567489 | |
| 3 | 結婚式の予定はいつ頃ですか | entry.127791430 | ✅ |
| 4 | どこでこのアプリを知りましたか | entry.789322737 | |
| 5 | こんな機能がほしい、という要望 | entry.2034343101 | |

**entry IDを変えるとLPからの送信が全部落ちる。** フォーム側で設問を作り直すときは
`index.html` の `name="entry.xxx"` も必ず合わせること。

### ⚠️ 要対応
接続テストの回答が**1件**入っている（`test-delete-me@example.com`／「接続テスト」）。
Forms APIに回答削除の口が無いため、フォーム編集画面の「回答」タブから手で消すこと。
